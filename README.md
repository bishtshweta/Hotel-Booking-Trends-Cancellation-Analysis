# Hotel Booking Trends & Cancellation Analysis

## Project Overview
Exploratory Data Analysis (EDA) of 119,390 hotel booking records to understand booking behavior, cancellation patterns, customer segments, and seasonal demand.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Exploratory Data Analysis (EDA)

## Key Activities
- Cleaned and preprocessed hotel booking data and handled missing values.
- Analyzed cancellation rates, booking lead times, customer origin, and seasonal booking patterns.
- Explored average daily rates (ADR), special requests, and customer segments.
- Created visualizations to identify trends and relationships in booking behavior.

## Key Findings
- Canceled bookings had a higher average lead time of 105.7 days compared with 70.1 days for non-canceled bookings.
- Identified seasonal demand patterns, including peak booking activity in August.
- Examined factors associated with booking cancellations to derive insights for hotel booking management.

## Business Value
The analysis highlights booking patterns and cancellation-related trends that can help inform reservation management, demand planning, and cancellation-reduction strategies.
